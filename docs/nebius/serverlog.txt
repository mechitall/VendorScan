Excerpt from the local API server log (python -m vendorscan.api). The lines are unchanged;
only Nebius decision calls and the API requests around them are kept. Includes test runs.

"nebius call ..." = one live Token Factory chat completion that chooses the next step
(vendorscan/next_action.py).
  model       model id on Token Factory
  buyer       buyer type the decision is for
  asked       action the model chose
  status      "model" = accepted by the safety rules; "rejected" = blocked
  latency_ms  duration of the call

Not in this log: the calls that read web sources (seller VAT, reputation, restock).
Lines have no timestamps and the Nebius lines do not name the product.
